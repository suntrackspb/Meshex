# Telegram-модуль на Python

Нужен Python 3.9 или новее. Модуль запускается из исходника и использует стандартную библиотеку Python. Все команды ниже выполняются из корня `Etohost-Mesh-Client`.

## Привязка аккаунта

```sh
python3 examples/bridges/telegram/python/telegram_bridge.py configure "$HOME/.meshex-telegram/python.json"
```

Введи токен от `@BotFather`, открой одноразовую ссылку и нажми **Start** в личном чате с ботом. Бот пришлёт ID аккаунта. Введи его в терминале для подтверждения. В файле конфигурации сохраняются токен бота, ID аккаунта и токен локального HTTP-подключения. Храни файл в своём пользовательском каталоге.

На Windows используй `python` вместо `python3` и замени путь к файлу, например, на `"$env:USERPROFILE\.meshex-telegram\python.json"` в PowerShell.

## Подключение по локальному HTTP

Этот режим подходит для готовой сборки Meshex на macOS с App Sandbox. Модуль запускается в терминале.

```sh
python3 examples/bridges/telegram/python/telegram_bridge.py serve "$HOME/.meshex-telegram/python.json"
```

В **Настройки → Мосты → Локальный HTTP** укажи адрес `http://127.0.0.1:8765` и токен HTTP-подключения, который напечатает модуль. Терминал должен оставаться открытым. При необходимости задай другой порт через `--port`.

## Подключение как внешний процесс

В **Настройки → Мосты → Внешний процесс** укажи абсолютный путь к `python3` или `python.exe`. В аргументах введи абсолютный путь к скрипту, `run` и путь к конфигурации, по одному на строку.

```text
/absolute/path/to/telegram/python/telegram_bridge.py
run
/absolute/path/to/python.json
```

В обоих режимах выбери ноду, разреши пересылку и отправку в нужных чатах, сохрани настройки и нажми **Запустить**. Используй один запущенный экземпляр модуля на один токен BotFather.

## Команды Telegram

- **Reply** на пересланное сообщение отправляет ответ в исходный mesh-канал или в личку.
- `/targets [поиск]` показывает адресатов, которым разрешено писать.
- `/send <номер> <текст>` отправляет новое сообщение выбранному адресату.
- `/mention <текст>` в ответ на сообщение канала упоминает автора и отвечает в канал.

- `/react <эмодзи>` в ответ на пересланное сообщение ставит реакцию в mesh.

Реакция из mesh приходит в Telegram сообщением с именем автора. Бот отвечает на исходное сообщение Telegram, если оно уже было переслано. Telegram Bot API требует прав администратора для получения нативных реакций пользователя, поэтому в личном чате для обратной реакции используется `/react`.

Стикеры из установленных паков бот отправляет в Telegram как стикер или как WebP-файл. Анимированный WebP передаётся файлом. Если медиа недоступно, бот показывает идентификатор стикера. Стикеры Telegram пока нельзя отправлять обратно в mesh.
