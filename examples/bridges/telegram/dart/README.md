# Модуль Telegram для Meshex

Модуль работает отдельным процессом и использует [публичный API Meshex](../../README.md) через стандартный ввод и вывод. Для запуска исходника нужен Dart SDK 3.9 или новее. Все файлы модуля находятся в этом каталоге, зависимости из репозитория Meshex ему не нужны.

## Привязка бота и аккаунта

1. Создай бота через BotFather и скопируй токен.
2. Запусти настройку в терминале. Подставь свой путь к файлу конфигурации в каталоге пользователя вне репозитория.

   ```sh
   dart ./examples/bridges/telegram/dart/telegram_bridge.dart configure /absolute/path/telegram.json
   ```

3. Введи токен. Открой одноразовую ссылку, нажми **Start** в личном чате с ботом и введи в терминале ID, который прислал бот. Модуль сохраняет токен и привязку в выбранном файле. Этот файл содержит секрет. Храни его в приватном каталоге и не отправляй другим людям. На macOS и Linux настройка создаёт его с правами `600`.
4. Для смены аккаунта останови мост в Meshex и снова запусти `configure` с тем же путём. Используй отдельного бота, если другой процесс или webhook уже получает обновления.

## Подключение к Meshex

В **Настройки → Мосты** выбери **Внешний процесс**. В поле исполняемого файла укажи полный путь к `dart` или `dart.exe`. В поле аргументов введи три строки:

```text
/absolute/path/to/telegram/dart/telegram_bridge.dart
run
/absolute/path/telegram.json
```

Выбери ноду, входящие сообщения и куда модулю можно отвечать. Сохрани настройки и нажми **Запустить**. Токен BotFather остаётся в конфигурации модуля. Передавать его в аргументах или вставлять в Meshex не требуется.

Модуль также можно собрать в отдельный исполняемый файл, чтобы запускать его без установленного Dart:

```sh
dart compile exe ./examples/bridges/telegram/dart/telegram_bridge.dart -o telegram-bridge
```

В этом случае вызывай `telegram-bridge configure /absolute/path/telegram.json` для настройки, а в Meshex укажи путь к бинарнику и две строки аргументов — `run` и путь к конфигурации. На Windows используй расширение `.exe`. Подписанная сборка Meshex с App Sandbox может ограничивать запуск внешних программ на macOS.

## Команды

- **Ответить** на пересланное сообщение — ответить в тот же mesh-канал или в личку исходному собеседнику.
- **`/targets [поиск]`** — запросить доступные для отправки каналы и ноды.
- **`/send <номер> <текст>`** — начать новое сообщение. Используй номер из списка, полученного после текущего запуска моста.
- **`/mention <текст>`** в ответ на сообщение канала — упомянуть автора и ответить в канал.
